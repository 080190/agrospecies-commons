# AgroSpecies Commons
Offline, farmer-owned AI for identifying agroforestry species and their benefits.

Problem: Farmers in Central Cameroon cut valuable trees because they can't identify them.

Solution: TensorFlow Lite running 100% offline on low-end Android. Federated learning - no data leaves phone. Educates on nitrogen fixation, shade, soil, income, best combinations.

Species: Albizia, Irvingia, Gliricidia, Moringa etc.
Stack: TFLite, Kotlin
